FarmAssist - projet complet (Fabric, Minecraft 26.1.2)

PRÉREQUIS : JDK 25 installé (https://adoptium.net) et connexion internet (1er build = téléchargements).

COMPILER
  Windows :  gradlew.bat build
  Linux/Mac: ./gradlew build

RÉSULTAT
  build/libs/farmassist-0.1.0.jar   <- à mettre dans .minecraft/mods (avec Fabric API)
  (ignore le fichier -sources.jar)

Si ça échoue : copie la dernière erreur et envoie-la.
